# CyberSafe — Phishing Detection Challenge

An interactive cybersecurity awareness quiz designed to help college students recognize common phishing warning signs.

## Built with
- HTML for page structure
- CSS for responsive layout
- JavaScript for sample emails, scoring, and feedback

## Run locally
Open `index.html` in a web browser. No server or account is needed.

## Project notes
All messages and domains are fictional (`.example` domains are reserved for documentation). The legitimate examples are educational, not guarantees that similar-looking emails are safe.

## Future improvements
- Add a progress indicator and difficulty settings
- Add more scenarios (QR-code scams, fake internships)
- Ask volunteers to test the quiz, record anonymous feedback, and improve unclear explanations

## Safety & privacy
No real login credentials, user accounts, network scanning, or external requests. The quiz runs entirely in the browser and doesn't collect personal data.
